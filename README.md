# My Git and GitHub Practice Project

## About This Project
This is my beginner project for learning Git and GitHub. I practiced creating repositories, tracking changes, and uploading files online.

## Project Files
- `hello.txt` — My first project file.
- `online.txt` — A file created on GitHub and downloaded using pull.
- `practice.txt` — A file used to practice cloning and pushing changes.

## What I Learned
- `git init` — Create a Git repository.
- `git add` — Prepare files for saving.
- `git commit` — Save a snapshot of changes.
- `git push` — Upload changes to GitHub.
- `git pull` — Bring changes from GitHub.
- `git clone` — Copy a repository to a new folder.
- `git log --oneline` — View commit history.
